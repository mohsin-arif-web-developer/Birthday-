# BSSE7ReactLab

A Vite + React project setup.

## Getting Started

1. Extract the ZIP archive.
2. Open terminal in the `BSSE7ReactLab` directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run dev server:
   ```bash
   npm run dev
   ```
5. Open http://localhost:5173 in your browser.
